# EPUB Workflow com Markdown e Pandoc

## Sobre o livro

Este livro apresenta um workflow prático para criar e-books em formato EPUB utilizando Markdown, Visual Studio Code e Pandoc.

A proposta é ensinar desde os fundamentos da escrita semântica em Markdown até a configuração do ambiente e a construção organizada de um projeto de e-book, incluindo estrutura de pastas, capítulos, imagens, metadados e comandos no terminal.

## Capítulos

### 1. Introdução ao Markdown e à semântica

- História e fundamentos do Markdown
- Semântica e estrutura dos documentos
- Importância da escrita semântica

### 2. Visual Studio Code para Markdown

- Instalação e configuração do VS Code
- Extensões para Markdown
- Organização e edição do projeto

### 3. Instalação e configuração do Pandoc

- Instalação do Pandoc
- Configuração inicial
- Comandos básicos e conversão de documentos

### 4. Workflow: construindo o e-book

- Estrutura de pastas e capítulos
- Imagens, metadados e arquivos Markdown
- Comandos do Pandoc e geração do EPUB
- Organização do projeto dentro do VS Code

### 5. Checklist e resumo

- Checklist do projeto
- Revisão dos arquivos e metadados
- Conversão e revisão final do EPUB
- Resumo do workflow completo
